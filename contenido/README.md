# Biblioteca de materiales didácticos de Coasocia

Esta carpeta es el repositorio editorial de recursos educativos. Los archivos pueden actualizarse directamente en GitHub; la publicación se sincroniza por Cloudflare Pages.

## Estructura

- lecturas/: lecturas breves para estudiantes, relacionadas con las actividades.
- guias/: orientaciones para docentes, con preguntas de acompañamiento y seguimiento.
- documentos/: archivos PDF y otros materiales de apoyo autorizados.
- plantillas/: modelo para crear nuevas experiencias de aprendizaje.
- Las fotografías, ilustraciones y fondos visuales deben agregarse en assets/imagenes/, conservando nombres descriptivos.

## Cómo publicar nuevas lecturas

1. Crear o editar un archivo Markdown en lecturas/ con un nombre corto y estable.
2. Revisar pertinencia, edad, legibilidad, procedencia de la información y derechos de autor.
3. Crear el enlace correspondiente dentro de aula.html, sección #recursos.
4. Confirmar la publicación en Cloudflare después del commit.
5. Nunca subir a GitHub contraseñas, PIN, datos identificables de estudiantes, respuestas reales ni documentos institucionales reservados.

Los materiales aquí incluidos se redactaron como recursos didácticos originales a partir de los ejes de indagación, trabajo colaborativo, interdisciplinariedad y seguimiento que aparecen en el corpus académico del proyecto. No representan resultados empíricos de una intervención.

## Advertencia de publicación

El repositorio GitHub es público, de modo que los archivos pueden consultarse allí directamente aunque el aula web exija inicio de sesión. Para materiales exclusivos de los grupos, deberá utilizarse almacenamiento privado y autorización desde el servidor en una fase posterior.
