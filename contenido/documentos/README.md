# Documentos complementarios

Almacena aquí archivos de consulta que tengas permiso de distribuir, como guías en PDF, rúbricas y fichas imprimibles para el alumnado. Utiliza nombres breves sin espacios y coloca enlaces desde el apartado Recursos del aula.

No almacenes datos de estudiantes ni materiales sujetos a restricciones de licencia. Los archivos de este repositorio son públicamente accesibles en GitHub.
