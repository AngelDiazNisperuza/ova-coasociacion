# Imágenes del OVA Coasocia

## Fondos ya conectados al diseño

Sube en `assets/imagenes/fondos/` archivos JPG con estos nombres exactos:

- `portada.jpg`: fotografía horizontal de portada, sugerencia 1920 × 1080 px.
- `reto.jpg`: fondo discreto de la actividad interdisciplinaria.
- `docentes.jpg`: fondo discreto de las orientaciones docentes.

La página seguirá mostrando sus colores de respaldo si todavía faltan estas fotos. Al subir cada imagen con su nombre exacto, se mostrará automáticamente sin editar el código.

## Otras carpetas

- `figuras/`: diagramas y esquemas propios o autorizados.
- `fotografias/`: fotos de actividades pedagógicas autorizadas.
- `logos/`: identidad y escudos institucionales autorizados.
- `iconos/`: elementos gráficos reutilizables.

Las imágenes de estas cuatro carpetas **no se mostrarán automáticamente** hasta integrar su ubicación en la página. Para cargar: abrir la carpeta de GitHub, elegir **Add file > Upload files**, arrastrar el archivo y pulsar **Commit changes**.

Utiliza nombres en minúsculas, sin espacios ni tildes; optimiza los JPG y verifica los derechos de uso y las autorizaciones para fotografías de menores. No publicar datos personales ni registros de consentimiento.
